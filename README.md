# Match Myocyte

Match Myocyte is a mobile-first browser match-3 game for iPhone, Android, and desktop browsers. It uses the provided splash screen, generated lab background art, a local PNG sprite atlas, canvas animation, and Web Audio music/SFX.

## Play

Open `index.html` directly or serve the folder with any static server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This repository is ready for GitHub Pages. Use the repository root as the Pages source.
